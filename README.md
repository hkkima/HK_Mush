# 🍄 포슬포슬 버섯농장

원목에 영양제를 뿌리고, 다 자란 버섯을 **쓱— 그어서** 수확하는 클릭 & 드래그 버섯 재배 인크리멘탈 게임.
(나메코 재배 키트는 조작 메카닉만 참고했고, 핵심 루프는 인크리멘탈 성장이다.)

## 실행

**▶ 플레이: <https://hkkima.github.io/HK_Mush/>** (`main`에 푸시하면 GitHub Actions가 자동 배포)

빌드가 필요 없는 순수 HTML/JS/Canvas 게임이다.

- `index.html`을 브라우저로 바로 열거나
- `npm start` → <http://localhost:8080>

## 조작

| 입력 | 동작 |
| --- | --- |
| 탭 / 꾹 누르기 | 영양제 뿌리기 (영양 게이지 충전 + 근처 버섯 성장 촉진) |
| 드래그 (긋기) | 궤적에 닿은 **다 자란** 버섯 수확. 한 번에 여러 개 = 콤보 보너스 |

## 핵심 루프

```
영양제 뿌리기 ─▶ 버섯 성장 ─▶ 그어서 수확 ─▶ 포자(✦) 획득
      ▲                                         │
      └──── 강화 구매 (자리·성장·가치·자동화) ◀──┘
                     │
        새 원목 해금 ─▶ 새 품종 발견 (도감 보너스)
                     │
        포자 방출(환생) ─▶ 균사(🧬) ─▶ 영구 강화
```

- **처음엔 느리게**: 자리 3칸, 성장 6초, 영양은 직접 뿌려야 한다.
- **나중엔 폭발적으로**: 30칸, 성장 속도 수천 배, 새싹 재생 0.1초 미만, 자동 분무기, 수확 달팽이가 알아서 굴러간다.

## 시스템

### 원목 (스테이지) — 7종
참나무 → 자작나무 → 이끼 고목 → 달빛 버드나무 → 수정 동굴 뿌리 → 세계수 가지 → 별빛 운석.
원목마다 기본 가치 배율과 고유 버섯 5종(일반/고급/희귀/영웅/전설)이 있다. 해금한 원목은 자유롭게 오갈 수 있다.

### 버섯 — 35종
희귀할수록 비싸고 늦게 자란다. 일부는 특수 효과를 가진다.

| 효과 | 설명 | 예 |
| --- | --- | --- |
| 💧 영양 충전 | 영양 탱크를 가득 채움 | 이슬 버섯, 거울 버섯, 서리 버섯 |
| ⏰ 시간 가속 | 자라는 버섯 전부 +50% 성장 | 시계 버섯, 유령 버섯, 현자 버섯 |
| ⚡ 연쇄 수확 | 다 자란 버섯을 전부 함께 수확 (콤보 누적) | 번개 버섯, 불꽃 버섯, 성운 버섯 |
| 🌫️ 포자 폭발 | 빈 자리마다 새싹이 돋음 | 말불버섯, 불사조 버섯, 블랙홀 버섯 |
| 🎉 버섯 축제 | 15초간 가치·성장 ×3 | 축제 버섯, 보름달 버섯, 프리즘 버섯 |
| 💪 거대 | 여러 번 그어야 수확 | 왕나메코(4), 코스모스(5), 세계수 버섯(6) |

### 강화 (포자) — 11종
버섯 자리, 영양제 농도, 성장 촉진제, 품종 개량, 영양 탱크, 연속 베기, 자동 분무기, 균사 재생, 희귀 포자, 대박 확률, 수확 달팽이.
포자를 어느 정도 모으면 하나씩 공개된다.

### 도감
- 새 품종 발견마다 모든 가치 +10%
- 품종별 누적 수확 10 / 100 / 1천 / 1만 / 10만 개마다 별 ★ → 그 버섯 가치 ×1.6, 모든 가치 +3%

### 포자 방출 (환생)
- 균사 = ∛(이번 회차 누적 포자 / 100만)
- 포자·강화·원목 초기화, **도감과 균사 강화는 유지**
- 누적 균사 보너스: 모든 가치 × (1 + 0.1 × √누적 균사)
- 균사 강화 9종: 황금 손길, 오래된 균사, 넓은 원목, 영원한 분무기, 행운의 균, 달팽이 군단, 원목 기억, 도감 연구, 겨울잠

### 오프라인 진행
최대 8시간. 자리를 비운 동안의 성장·달팽이 수확을 시뮬레이션해 50%(균사 강화로 최대 100%)를 지급한다.

## 개발

```bash
npm test                 # 게임 로직 테스트 (node:test)
npm run sim -- 6 1       # 밸런스 시뮬레이션: 6시간, seed 1
EVERY=60 NOPRESTIGE=1 npm run sim -- 1   # 1분 간격 출력, 환생 없이
```

```
index.html          화면 골격
css/style.css       UI 스타일 (데스크톱: 좌 원목 / 우 패널, 모바일: 상 원목 / 하 패널)
js/format.js        숫자·시간 표기 (K, M, B, T, Qa …)
js/data.js          밸런스 데이터: 원목, 버섯, 강화, 균사 강화 ← 수치 조정은 여기서
js/game.js          게임 로직 (DOM 무관, 노드에서도 실행)
js/render.js        캔버스 렌더링: 절차적 버섯 그림, 배경, 파티클, 스와이프 궤적
js/ui.js            HUD, 탭 패널, 토스트, 모달
js/main.js          입력 처리, 메인 루프, 저장/불러오기
tools/balance-sim.js  봇 플레이 밸런스 시뮬레이터
tests/              로직 테스트
docs/DESIGN.md      밸런스 설계 노트
```

진행 상황은 브라우저 `localStorage`에 자동 저장된다(15초마다 + 탭 전환/종료 시). 기록 탭에서 저장 코드 내보내기/불러오기가 가능하다.
