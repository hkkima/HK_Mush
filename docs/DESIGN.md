# 밸런스 설계 노트

## 목표 곡선

"처음엔 느리지만 나중엔 폭발적인 성장 & 빠른 리젠"

| 구간 | 체감 | 수단 |
| --- | --- | --- |
| 0~10분 | 손으로 뿌리고 손으로 긋는다 | 자리 3칸, 성장 6초, 영양은 탭으로만 |
| 10~35분 | 원목이 바뀔 때마다 숫자 단위가 뛴다 | 원목 기본 가치 ×10~×50 점프, 도감 보너스 |
| 35분~ | 환생 한 번마다 원목을 몇 개씩 뚫는다 | 균사 보너스 + 균사 강화, 원목 기억 |
| 후반 | 원목이 버섯 분수처럼 돌아간다 | 성장 ×수천, 재생 0.1초 미만, 자동 분무기, 달팽이 군단 |

## 폭주 방지 원리

곱연산 강화의 효율 지수는 `ln(레벨당 효과) / ln(레벨당 비용 증가율)`이다.
포자 S를 전부 강화에 쓰면 수입은 대략 `S^(지수 합)`에 비례하므로:

- 지수 합 < 1 → 다항식 성장 (통제 가능)
- 지수 합 ≥ 1 → 초지수 폭주 (몇 분 만에 Infinity)

첫 설계(가치 ×1.2/1.55, 행운이 전설 가중치에 luck² 적용)는 지수 합이 1을 넘어 **12분 만에 모든 원목을 뚫고 2시간 만에 Infinity**에 도달했다.
현재 수치:

| 강화 | 효과/레벨 | 비용 증가율 | 지수 |
| --- | --- | --- | --- |
| 품종 개량 | ×1.18 | ×1.9 | 0.26 |
| 성장 촉진제 | ×1.12 | ×1.9 | 0.18 (수확 속도에 막혀 실효는 더 낮음) |
| 희귀 포자 | 가중치 ×1.25^(tier/4) | ×2.2 | ≤0.28 (전설 비중이 포화되면 0) |

나머지(자리, 콤보, 대박, 별, 도감)는 상한이 있는 배율이다.

환생 루프도 같은 원리다. 균사 = ∛포자, 누적 보너스 = √균사 → 포자 대비 지수 1/6.
균사 강화(황금 손길 ×1.5 / 비용 ×3)까지 더해도 회차 간 성장이 수렴하도록 맞췄다.
(선형 보너스 `1 + 0.05×균사`일 때는 회차마다 균사가 3 → 2,709 → 1,500만 → 1,000억으로 폭주했다.)

## 시뮬레이션 결과

`npm run sim -- 4 <seed>` — 매우 부지런한 봇(초당 탭 3회, 0.8초마다 긋기, 가장 싼 강화부터 구매) 기준.

| 이정표 | seed 1 | seed 2 | seed 3 |
| --- | --- | --- | --- |
| 자작나무 | 12분 | 11분 | 12분 |
| 이끼 고목 | 19분 | 21분 | 20분 |
| 달빛 버드나무 | 32분 | 32분 | 31분 |
| 수정 동굴 (환생 2회 후) | 35분 | 36분 | 36분 |
| 세계수 | 52분 | 53분 | 53분 |
| 별빛 운석 | ~2시간 15분 | | |

실제 플레이어는 봇보다 덜 부지런하므로 체감 시간은 이보다 길다.

## 조정 손잡이 (`js/data.js`)

- 초반 속도: `LOGS[0].growTime`, `UPGRADES.slots/spray` 비용
- 원목 간 간격: `LOGS[].cost` (다음 원목 비용 ÷ 현재 원목 기본 가치가 클수록 오래 걸림)
- 후반 폭발감: `UPGRADES.growth/regen/snail` 최대 레벨, `PUPGRADES.p_growth`
- 환생 주기: `PRESTIGE_BASE`, `MYC_BONUS`, `PUPGRADES.p_value.growth`
